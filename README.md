# Promo Watcher

Discord-бот, который мониторит RSS-источники, ищет свежие упоминания промокодов, оценивает их качество и отправляет результат в один канал.

## Что уже делает

- читает источники из `config.json`
- ищет коды по тексту постов и новостей
- отсекает слишком старые записи
- не шлет дубли
- для плохих сигналов допускает повтор раз в `30` минут
- отправляет embed-сообщения в Discord-канал

## Быстрый запуск

1. Создай `.env` по примеру `.env.example`
2. Установи зависимости:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

3. Запусти бота:

```powershell
python app.py
```

## Настройки

Все источники и правила находятся в `config.json`.

- `poll_interval_minutes` — интервал опроса
- `max_post_age_hours` — сколько максимум живут обычные сигналы
- `max_bad_post_age_hours` — сколько максимум живут плохие сигналы
- `bad_repeat_minutes` — как часто можно повторять плохие сигналы
- `sources` — список RSS-источников

## Ограничения текущей версии

- пока используются только RSS и новостные потоки
- X, Telegram и Discord как источники пока не подключены
- оценка "рабочий/нерабочий" эвристическая, без автоматического ввода промокодов
